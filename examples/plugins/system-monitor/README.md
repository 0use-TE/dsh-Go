# 系统监控

[English](README.en.md)

为 DSH Ha / dsh-Go 提供一个 Web 插件页签，查看 Ubuntu / Linux 当前可读取的资源、进程与端口。无需修改 APK，无额外 npm 依赖，无后台采集进程。界面沿用宿主主题和中文／英文语言设置。

## 功能和范围

- 「资源」每两秒更新 CPU、内存、存储和可见进程；进程可按 CPU 或 RSS 内存排序，最多显示前 12 项。不提供结束进程按钮。
- 系统 CPU 使用两次 `/proc/stat` 的差值。读取受限时显示「Ubuntu CPU」，统计两次采样之间可见进程的 CPU 时间，单核满载为 100%，多核可以超过 100%。第一帧显示采样中。PID 复用通过进程启动时间区分。
- 内存是 `/proc/meminfo` 中设备可用的总内存，已用量为 `MemTotal - MemAvailable`，不是把 Linux 缓存全部当作已用。存储是 Ubuntu 主目录所在分区，使用 `statfs`，不把整个分区大小当成 Ubuntu 文件占用。
- 「端口」每五秒更新当前网络环境可读取的 TCP 监听、UDP 绑定、IPv4／IPv6 地址，以及能通过进程文件描述符确认的 PID 和进程名。不读取完整命令行、环境变量或凭据，不扫描远端端口，不修改防火墙。
- Android PRoot 没有真正的系统 root 权限。部分设备限制 `/proc/stat`、`/proc/net/*` 或其他进程：受限项明确说明，不把失败当成空表或零占用。只承诺当前 Ubuntu 可见范围，不承诺覆盖 Termux 或其他 Android 应用。
- 若已安装服务管理插件，同一 `DSH_HOME` / `DSH_SVC_HOME` 下的登记地址单独显示，明确标注「不代表正在监听」。系统监控可以单独安装；登记地址读取不依赖服务管理运行，也不会启动或停止服务。
- 所有接口沿用 DSH 主机的认证／来源检查，仅允许读取。资源与端口请求分别合并并缓存一秒／五秒，未打开界面时不定时采集。

## 安装

在实际运行 DSH 引擎的 Ubuntu / Linux 环境中复制完整插件目录，然后执行：

```sh
P="${DSH_HOME:-$HOME/.dsh}/dsh-go/plugins/system-monitor"
dsh plugin --profile web add "$P"
```

首次安装后重载插件或重启一次引擎。面板位于对话详情的「插件」里，DSH Ha 也可使用已有的独立显示开关。前端更新使用宿主客户端热重载，后端采集代码更新需要重载插件或重启引擎。

## 验证

```sh
npm run check
npm test
```

测试覆盖计数器、PID 复用、IPv4／IPv6、监听过滤、占用进程映射、受限读取及认证边界。真机读取能力以设备实际返回为准。
