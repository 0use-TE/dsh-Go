# 终端

对话的终端：和 AI 用同一个工作区跑命令。命令在主机上执行，也就是你的电脑或服务器上。

鸿蒙版的本机引擎没有交互终端：在本机的对话里打开，页面会写着**这个连接用不了终端**，提示可以连 SSH 主机。要用终端，先[添加 SSH 主机](03-engine-hosts.md#添加-ssh-主机)，在那台主机的对话里打开。

终端属于当前对话，先打开一个对话。

## 对话中的终端面板

终端固定在聊天下方，不加载插件。点击输入框右侧、发送／语音按钮旁的终端图标，或右上角的终端按钮，即可展开／隐藏；也可按实体键盘 Ctrl + 反引号键切换。隐藏后不占底部空间，展开后没有额外标题栏。拖动上方的分隔缝调整高度；多个终端页签紧凑横排在面板顶部，过多时可横向滚动；新建按钮位于标签栏右侧；右键或长按页签会在按下的位置弹出上下文菜单，可重命名或删除对应终端；删除运行中的终端仍会要求确认。按 Ctrl + 1～9 选中对应终端，隐藏时也可直接展开并选中。原来的全屏终端仍可从全部功能打开。快捷键在当前聊天页优先处理，不受聊天输入框、终端或原生插件控件焦点影响；弹窗、其他页面和覆盖聊天页的抽屉打开时暂停。Ctrl + 反引号同时识别实体键位置，兼容输入法或键盘布局改变逻辑键值的情况。

面板不显示手机辅助按键行，直接使用实体键盘的组合键；全屏终端仍保留辅助按键行。面板和全屏页面共用当前对话的终端页签。隐藏面板不关闭终端，也不再接收键盘输入；再次展开恢复页签和内容。用 `+` 新建多个终端，关闭页签才结束对应进程。

## 终端快捷键与左右分屏

| 快捷键 | 操作 |
|---|---|
| Ctrl + 反引号 | 展开／隐藏终端面板 |
| Ctrl + Shift + 反引号 | 新建终端并聚焦，面板隐藏时先展开 |
| Ctrl + Shift + W | 关闭当前终端，运行中的终端仍会要求确认 |
| Ctrl + Shift + 5 | 向右分屏，新建一个独立终端 |
| Ctrl + 1～9 | 选择对应终端 |

新建和面板切换在当前聊天工作区生效；关闭、分屏只在终端获得焦点时生效，弹窗与覆盖聊天页的抽屉打开时暂停。分屏同时支持左右两个终端组，每组顶部都有自己的横排页签，标签栏右侧保留新建按钮，只显示本组的终端；输入、选择和滚动各自独立。点击内容或页签切换当前终端。拖动中间的竖直分隔缝调整宽度。已分屏时再次按分屏快捷键不再创建窗格。

右键或长按面板顶部页签，选择“向右分屏”或“取消分屏”。取消分屏只保留当前终端的显示，其他终端继续在页签中运行；关闭当前页签后优先显示同组的其他终端，只有整组关空时另一侧才自动铺满。点击某组的新建按钮就在该组创建终端，快捷键新建则加入当前获得焦点的组；选择页签只改变所属组的显示，另一组不受影响。隐藏后再次展开会恢复分屏和宽度；离开工作区后不保存分屏布局。

## 右侧插件 Tab 与拆分

默认保留 DSH Go 原来的“插件”导航项：点击后，多个插件视图显示为列表，再点击某个视图查看；只有一个视图时沿用原来的直接展示方式。在已安装插件的详情页开启“独立显示”，宽屏下该插件会从详情的“插件”页移到右侧外层工作区，关闭后回到原来的“插件”页。同一插件不会同时出现在这两处。显示方式按主机和插件包名保存在 App 本地；已有商店插件默认使用原来的入口和加载逻辑。窄窗口仍使用原来的“插件”页；全部功能及管理入口保留。

鼠标或触摸板按住页签拖动，触屏长按页签后拖动；拖到其他外层页签左／右侧可调整顺序，相邻页签以滑动动画让位。拖到内容区上方或下方可拆分为上下两块；拆分后拖到另一块可移动页签。对话详情也可以移动。每个页签只在一块中显示，移走最后一个页签后自动合并；拖动分隔缝调整高度。拖动预览只显示高亮区域，没有“放到上方／下方”等文字。布局和页签顺序按主机保存。拖动右栏与聊天区之间的竖直分隔线可调整右栏宽度，宽度会记住；聊天区保留最小宽度。右栏收起或窗口不足以显示右栏时，没有拖动手柄。左侧列表展开／收起、窗口改变时会重新限制宽度，拖动本身不会让左栏突然展开或收起。窗口放不下右栏时，插件仍可通过原入口使用，终端始终留在聊天下方。

Node.js 插件仍在原来的引擎中加载和运行。新入口复用现有的原生面板、Web 界面或 Web 打开入口，权限、作用域及显示规则保持原有行为，不需要另一套插件格式。

## 配色

<!-- nav: commonSettings,hubSettingsInterface,terminalColorTitle -->
`设置 › 界面 › 终端配色`

默认使用经典黑色，也可选择深蓝色。切换即时生效，面板与全屏终端共用配色，不会重建终端进程。

## 页签

- 打开页面时，主机上保留的终端会逐个恢复；一个都没有就新建一个。
- 每个页签是主机上的一个独立终端，常驻在主机上，不随手机界面关闭。
- 离开页面只是断开显示：命令继续在主机上跑，回到页面会重新接上。
- 关掉页签才会结束里面的进程。进程已经结束的页签停在结束状态，不会自动重开。

## 按键

键盘上方的按键行是终端常用的控制键，比如中断、退出、补全和方向键；需要组合键时先点修饰键再点按键。

## 注意

- 终端里的命令以主机上的用户身份运行，能读写主机上的文件；App 不会逐条替你确认命令。
- 远程主机断开后，终端还在主机上跑；重新连上再打开页面就能接回。
