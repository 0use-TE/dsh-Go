# 系统监控

[English](README.en.md)

为 DSH Ha / dsh-Go 提供一个 Web 资源面板，查看 Ubuntu / Linux 当前可读取的 CPU、内存、存储和进程。无需修改 APK，无额外 npm 依赖，无后台采集进程。界面沿用宿主主题和中文／英文语言设置。

## 功能和范围

- 面板直接显示 CPU、内存、存储和「进程」，每两秒更新。点击 CPU 或内存列标题排序，最多显示前 12 项。不提供结束进程按钮。
- 系统 CPU 使用两次 `/proc/stat` 的差值。读取受限时改为统计两次采样之间可见进程的 CPU 时间，单核满载为 100%，多核可以超过 100%。首次采样显示破折号；范围说明通过悬停提示查看。PID 复用通过进程启动时间区分。
- 内存是 `/proc/meminfo` 中设备可用的总内存，已用量为 `MemTotal - MemAvailable`，不是把 Linux 缓存全部当作已用。存储是 Ubuntu 主目录所在分区，使用 `statfs`，不把整个分区大小当成 Ubuntu 文件占用。
- 不显示端口页、更新频率或范围说明等辅助小字。PID 和统计含义通过悬停提示查看；正文和进程表均为 16px，主要数值为 24px。无端口采集或服务登记表读取。
- Android PRoot 没有真正的系统 root 权限。读取不到的数值保持未知，不伪装成零占用。只承诺当前 Ubuntu 可见范围，不承诺覆盖 Termux 或其他 Android 应用。不读取命令行、环境变量或凭据。
- 接口沿用 DSH 主机的认证／来源检查，仅允许读取。并发请求合并并缓存一秒，未打开界面时不定时采集。

## 安装

在实际运行 DSH 引擎的 Ubuntu / Linux 环境中复制完整插件目录，然后执行：

```sh
P="${DSH_HOME:-$HOME/.dsh}/dsh-go/plugins/system-monitor"
dsh plugin --profile web add "$P"
```

首次安装后重载插件或重启一次引擎。面板位于对话详情的「插件」里，DSH Ha 也可使用已有的独立显示开关。前端更新使用宿主客户端热重载，后端采集代码更新需要重载插件或重启引擎。

## 验证

```sh
npm run check

```

测试覆盖计数器、PID 复用、缓存、受限读取及认证边界。真机读取能力以设备实际返回为准。
