# 客户端提示词模板

推荐从「服务管理」面板复制提示词，它会自动包含插件绝对路径。手工使用本模板时，把 `<插件绝对路径>` 替换为当前 DSH 主机中 `local-services` 目录的实际路径。

需要持续运行的 Web 或后台服务，必须通过本机服务管理器登记并启动。入口是 `node '<插件绝对路径>/bin/dsh-svc.mjs'`，先运行 `--help`。

1. 使用 `start 名称 --cwd 绝对目录 [--url http://127.0.0.1:端口] [--autostart] -- 程序 参数`，一步登记并启动。
2. 使用前台运行命令。不要使用 `nohup`、`&`、后台化参数、`systemctl enable`，也不要让服务依赖临时终端存活。
3. 使用 `list` 核对进程状态，使用 `logs 名称` 查看输出。登记本机 HTTP 地址后，分别报告进程与网页就绪状态；不要把“启动命令已接受”等同于网页可访问。
4. 使用 `stop`、`restart`、`autostart 名称 on|off`、`remove` 管理。先停止再修改配置；移除只用于已停止的服务，并会删除插件保留的日志。
5. 自启指随 DSH 引擎／插件加载恢复，不是 Android 开机自启。只有用户要求时才能开启。手动停止不清除自启设置；取消下次恢复需要关闭自启。
6. 失败如实报告，超时或断线后先 `list` 核对，避免启动重复服务。不要读取 systemd 状态来推断插件中的服务状态。
7. 命令参数和 URL 会被持久保存，输出会写日志。密钥使用程序自己的私有配置文件，不写入参数、URL 或日志。
8. 临时构建、测试和一次性命令仍可使用普通终端。不要把所有短命令都登记成服务。
